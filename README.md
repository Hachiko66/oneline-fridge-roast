A one-line roast for a fridge that updated its firmware overnight and now
demands a small ritual before it will make ice. The setup promises a smart
appliance; the punchline admits it is haunted.

> My fridge updated its firmware overnight and now the ice maker only works if I press the button twice and whisper to it — it's not smart, it's haunted.

Run it with: python3 main.py
